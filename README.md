# Selenium Automation Framework (Java)

## 📌 Overview
This project is a test automation framework built using Selenium WebDriver with Java.  
It is designed to automate web application testing with scalable and maintainable architecture.

---

## 🚀 Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- Git

---

## 🧩 Framework Design
- Page Object Model (POM)
- Data-Driven Testing
- Reusable utilities and components
- Modular and scalable structure

---

## 🔧 Features
- Automated functional and regression test cases
- Cross-browser testing support
- Easy test execution using TestNG
- Structured reporting
- Clean and maintainable code design
